# Sara Portfolio

A simple and responsive portfolio website built for Sara to showcase her work, skills, and contact information.

## Built With

* HTML
* CSS
* JavaScript
* Bootstrap

## Features

* Responsive design
* About section
* Skills section
* Projects section
* Contact section
* Mobile-friendly layout

## Run Locally

Clone the repository and open `index.html` in your browser.

git clone https://github.com/AhmedMohamed878/portofolio-Sara.git
